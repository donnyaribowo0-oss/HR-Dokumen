# HR-Dokumen

Repository dokumen HR & Legal Grup Yong Hee Edu (KSI, KIA, CT).

## Struktur Utama

### 01-Dokumen-Lama
Arsip dokumen dan template asli sebelum revisi/audit. Dijadikan referensi sejarah, bukan acuan kerja aktif.

### 02-Hasil-Revisi
Dokumen final hasil audit dan penyusunan ulang bersama. Ini adalah acuan kerja aktif (baseline). Setiap file final diberi akhiran `-FINAL`, draft yang masih berjalan diberi akhiran `-DRAFT`. Perubahan pada dokumen final selalu ditandai bold pada bagian yang berubah dibanding versi sebelumnya.
